CMS / CONFIGURATION REQUIRED

Connect your studio.

V2 is running from its bundled portfolio. To enable real logins, permanent media uploads and published changes, connect Supabase first.

  1. Create a Supabase project and run the SQL in supabase/schema.sql.
  2. Run supabase/seed.sql, then invite your admin email and authorize its user ID.
  3. Paste the public Supabase URL and publishable / anon key into js/config.js and redeploy.
Never paste a service-role key or private password in your website files.
